# Реализация

Приложение использует React, Vite и Tailwind CSS v4. Точка входа страницы: `src/App.tsx`. Оформление: `src/index.css`. Шрифты поставляются локально через установленные пакеты Fontsource, без обращения к Google Fonts.

В `src/fonts.css` подключены только необходимые WOFF2-подмножества с явными диапазонами символов. Лицензии шрифтов включены в `public/font-licenses.txt`.

## Редактирование

- `src/content.ts`: контакты, адрес, ссылки, цены, длительность, услуги, обучение, FAQ, отзыв, изображения и юридические поля.
- `docs/page-content.md`: структура и итоговые тексты страницы.
- `index.html`: основные SEO-метаданные и fallback без JavaScript.
- `public/favicon.svg`: монограмма.

## Запись и форма

Все основные кнопки записи ведут по предоставленной ссылке BookNow. Сайт не создаёт запись самостоятельно и не обещает наличие свободного времени.

Форма проверяет имя, телефон и подтверждение условий. После проверки отображается черновик. Посетитель открывает реальный личный чат https://t.me/pycoyk и сам отправляет сообщение. Формат ссылки с параметром `text` соответствует документации Telegram: https://core.telegram.org/api/links#public-username-links.

Предусмотрены копирование сообщения и возврат к редактированию. Нет запросов к вымышленному API, сохранения данных в localStorage или ложного сообщения «Заявка отправлена».

Точка для последующей серверной интеграции обозначена комментарием в `ContactForm.handleSubmit`. Перед интеграцией необходимы реальный endpoint, обработка отказов, реквизиты оператора и утверждённые документы о персональных данных. Текущая версия не выполняет серверную отправку.

## Изображения

Вложения видны в переписке, но не переданы в файловую систему проекта. Используются изображения с публичной страницы этой же практики: https://zdravidar.booknow.ru/. Источники записаны в `src/content.ts`. Внешность не изменяется, генерация изображений не применялась. Вёрстка использует только масштабирование и кадрирование CSS.

Изображения обслуживаются существующим сервером BookNow в WebP. При ошибке загрузки предусмотрен переход к оригинальному JPEG. Галерея позволяет открыть изображение целиком, переключать фото кнопками и стрелками клавиатуры, закрыть просмотр клавишей Escape.

Чтобы убрать зависимость от внешнего сервера, разместите оригиналы в `public/images/` и замените `original` в `portrait` и `spacePhotos` на локальные пути вида `/images/vladimir-kurto.jpg`. Для подтверждения точного совпадения с приложенными фотографиями нужна визуальная сверка этих исходников.

## SEO и размещение

Подготовлены русский язык документа, Title, description, Open Graph, canonical, robots.txt, один основной H1, заголовки секций и JSON-LD ProfessionalService / FAQPage. Не добавлены вымышленные рейтинги, стаж, медицинская лицензия или сведения о полученном дипломе НГМУ.

Адрес страницы: `/kineziolog-novosibirsk/`. Корень `/` также показывает лендинг. В dev-сервере Vite маршруты обслуживаются SPA fallback. Файл `public/_redirects` задаёт маршрут для хостингов, поддерживающих формат Netlify. На другом хостинге для этого пути нужно включить отдачу `index.html`. Домен не выдуман: canonical получает фактический origin размещения. После выбора постоянного домена рекомендуется записать полный canonical и `og:url` непосредственно в `index.html` и подготовить sitemap для этого домена.

## Данные перед публикацией

- Статус СПО, НГМУ, 2028: уточнить. На странице прямо указано, что запись не подтверждает уже полученный диплом.
- Опыт: заполнить `practice.experience`.
- Сертификаты: добавить подтверждённые ссылки в `practice.certificates`.
- Юридические документы: заполнить `practice.legal`. Если заданы `privacyUrl` и `consentUrl`, ссылки открывают готовые документы; иначе открываются явно обозначенные проекты.

Внешние сервисы и наличие свободных временных слотов контролируются их владельцами. Успешная сборка не заменяет проверку записи в BookNow, открытия Telegram/MAX на реальных устройствах и юридическую проверку перед публикацией.

## Границы проверки

Проверены исходные контактные данные, длительность, стоимость, отсутствие неподтверждённых обещаний, структура ссылок и производственная сборка Vite. Проверка в реальном браузере и на физических мобильных устройствах в этой среде не выполнялась. Отправка реальной заявки и создание тестовой записи не осуществлялись.
